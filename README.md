# 黑带备考冲刺｜每日一练 PWA V2.1 知识库增强版

这是 V2.0 BYOK AI 版的增量升级。基础练习仍然完全离线可用；新增本地黑带知识库，用于学员交卷后的复盘、错题解释、复习优先级和 AI 上下文。

## V2.1 新增

### 1. 本地黑带知识库

新增 `knowledge.js`，目前覆盖题库中全部 42 个知识主题，并按 9 个 CSSBB BOK 模块组织：

- I 组织级规划与部署：12 / 150
- II 组织过程管理与指标：10 / 150
- III 团队管理：18 / 150
- IV Define：20 / 150
- V Measure：25 / 150
- VI Analyze：22 / 150
- VII Improve：21 / 150
- VIII Control：15 / 150
- IX DFSS：7 / 150

每个知识主题只保留适合冲刺复盘的摘要，不复制教材正文，结构包括：

- 对应 BOK 模块与认知层级
- 核心概念
- 公式 / 判断抓手
- 常见陷阱
- 教材章节导航

整理依据：

- `CSSBB_BOK(1).pdf`
- `The Certified Six Sigma Black Belt Handbook, Third Edition`
- `注册六西格玛黑带手册（第2版）`

### 2. 交卷后自动“知识库复盘”

交卷后除了原有得分、标准解析和复习建议，会自动显示最多 4 个需要优先复习的知识卡片。错题优先，并结合 BOK 模块题量排序。

每道错题下面也新增可展开的“知识库补充”，方便立即查看该知识点的核心与常见陷阱。

### 3. 实考预估改为 BOK 加权

预估不再只看总体正确率。V2.1 会结合：

- 9 个 BOK 模块的题量权重
- 学员在各模块的累计表现
- 全局正确率
- 最近 5 次练习走势
- 尚未覆盖模块带来的不确定性

输出仍为“备考趋势估计”，不是任何认证机构公布的官方分数换算或及格线。

### 4. AI 诊断接入本地知识库

AI 仍然是可选 BYOK 功能。只有用户主动开启并点击 AI 诊断/追问时才调用外部模型。

发送给 AI 的内容仅限于完成诊断所需的信息，包括：

- 当日题目和答题结果
- 题库标准答案与标准解析
- 近期练习表现
- 对应错题主题的本地知识库摘要
- BOK 模块风险与权重

AI 提示词明确要求：题库标准答案是判题依据，知识库是解释依据，不得擅自更改答案，也不得虚构官方考试规则。

## 题库现状

当前仍使用已经核对的 81 道题，来源于模拟测试题 2、3、4、5。扫描不清、图表依赖强或 OCR 容易产生歧义的题暂未纳入。

用户这次同时提供的两份 `CSSBB_Question_Bank` 还没有直接混入每日抽题池。建议先做题目、答案和图表完整性核验，再作为下一阶段的题库扩容来源。

## 部署到 GitHub Pages

1. 解压本 ZIP。
2. 用解压后的全部文件覆盖 GitHub Pages 仓库根目录。
3. 提交并 push。
4. 等待 GitHub Pages 重新发布。
5. 手机端若仍看到旧版，可关闭页面后重新打开；必要时清除该站点缓存。

V2.1 Service Worker 缓存名已升级，且加入 `knowledge.js`，首次成功打开后知识库可离线使用。

## 数据与隐私

基础模式下，昵称、答题记录、历史表现和知识库均保存在学员自己的浏览器设备中，不发送到课程方服务器。

AI 模式下，API Key 由学员自行填写；默认仅保存在当前会话。只有学员主动勾选“在本设备保存”时才写入本地存储。浏览器直连第三方 AI 服务存在客户端 Key 可被设备使用者查看的固有限制，因此建议只在个人设备使用，并设置合理的 API 额度上限。
