# 黑带备考冲刺｜每日一练 PWA V2.2

V2.2 基于 V2.1.1 热修复版，新增“黑带考试倒计时”。基础练习、知识库、BOK 加权实考预估、BYOK AI 和微信群打卡功能保持不变。

## V2.2 新增：考试倒计时

- 首页增加“黑带考试倒计时”卡片。
- 学员自行设置考试日期，日期只保存在当前设备，不上传服务器。
- 自动显示剩余天数、考试日期与备考阶段。
- 阶段规则：
  - 30 天以上：系统复习期
  - 15–30 天：强化训练期
  - 7–14 天：冲刺期
  - 1–6 天：考前决战
  - 考试当天：今天考试
- 倒计时卡片同步显示：今日进度、累计练习题数、当前实考预估。
- 做题中途退出回首页，今日进度会显示已答题数，例如 4/10。
- 打卡图会自动加入“距考试 X 天 / 当前阶段 / 考试日期”。
- 可随时修改或清除考试日期。

## 其他核心功能

- 每日固定抽取 10 题。
- 自动评分与逐题标准解析。
- CSSBB BOK + 黑带手册本地知识库复盘。
- 按 BOK 模块权重计算滚动实考预估及区间。
- 复习重点与薄弱知识点识别。
- 可选 BYOK AI 学习助手：学员自行填写自己的 API Key。
- 生成手机竖版打卡图并通过系统分享/微信分享。
- PWA：iPhone 与 Android 均可添加到主屏幕。

## GitHub Pages 部署 / 升级

当前线上地址如为：

`https://derekxujian.github.io/blackbelt-daily/`

最简单的升级方式：

1. 解压 V2.2 ZIP。
2. 进入 GitHub 仓库 `blackbelt-daily`。
3. 上传解压后的全部文件到仓库根目录，同名文件选择覆盖/提交。
4. Commit changes。
5. 等待 GitHub Pages 自动重新发布。
6. 打开网站后强制刷新一次；如仍看到旧版本，可清除此站点缓存再打开。

V2.2 Service Worker 缓存名为 `bb-daily-v2.2.0`，会逐步替换旧缓存。

## 文件说明

- `index.html`：页面结构与倒计时 UI
- `styles.css`：界面样式（保留 `[hidden]{display:none!important}` 热修复）
- `app.js`：倒计时、抽题、评分、复盘、BOK 预估、AI BYOK、打卡图
- `questions.js`：已核对模拟题题库
- `knowledge.js`：本地黑带知识库
- `manifest.webmanifest`：PWA 配置
- `sw.js`：离线缓存
- `icons/`：应用图标

## 数据与隐私

基础模式下，考试日期、昵称、答题记录、历史表现均保存在学员自己的浏览器设备中，不发送到课程方服务器。

AI 模式下，API Key 由学员自行填写；默认只保存在当前会话。只有学员主动勾选“在本设备保存”时才写入本地存储。
