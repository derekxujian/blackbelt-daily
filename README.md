# 黑带备考冲刺｜每日一练 PWA V2.3

V2.3 在 V2.2 考试倒计时版基础上，新增“每日题量 + 难度”自定义，并强化打卡图片里的连续打卡展示。

## V2.3 新增

### 1. 每日题量可自定义
学员可在首页选择：
- 5 题
- 10 题
- 15 题
- 20 题

当天开始练习后，题量与难度会锁定，避免中途改变导致进度错乱。完成当天练习后可重新设置，下一次练习生效。

### 2. 难度可自定义
可选择：
- 低：基础巩固
- 中：标准难度
- 高：高难挑战

抽题使用题库中的 difficulty 标签做加权，同时继续优先覆盖未做题，并在题库轮完后提高历史错题的抽取概率。

### 3. 打卡图强化连续打卡
生成的打卡图片会明确显示：
- 今日得分
- 答对题数 / 今日总题数
- **连续打卡 X 天**
- 滚动实考预估
- 今日复习重点
- 今日题量与难度
- 如已设置考试日期，还会显示距考试天数与冲刺阶段

## 其他核心功能

- 自动评分与逐题标准解析。
- CSSBB BOK + 黑带手册本地知识库复盘。
- 按 BOK 模块权重计算滚动实考预估及区间。
- 复习重点与薄弱知识点识别。
- 考试倒计时。
- 可选 BYOK AI 学习助手：学员自行填写自己的 API Key。
- 生成手机竖版打卡图并通过系统分享/微信分享。
- PWA：iPhone 与 Android 均可添加到主屏幕。

## GitHub Pages 升级

如果当前线上地址是：

`https://derekxujian.github.io/blackbelt-daily/`

最简单的升级方式：

1. 解压 V2.3 ZIP。
2. 进入 GitHub 仓库 `blackbelt-daily`。
3. 上传解压后的全部文件到仓库根目录，同名文件覆盖并提交。
4. Commit changes。
5. 等待 GitHub Pages 自动重新发布。
6. 打开网站后强制刷新一次；如仍看到旧版本，可清除此站点缓存再打开。

V2.3 Service Worker 缓存名为 `bb-daily-v2.3.0`。

## 数据与隐私

基础模式下，考试日期、昵称、每日题量、难度、答题记录、历史表现均保存在学员自己的浏览器设备中，不发送到课程方服务器。

AI 模式下，API Key 由学员自行填写；默认只保存在当前会话。只有学员主动勾选“在本设备保存”时才写入本地存储。
