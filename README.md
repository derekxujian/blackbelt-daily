# 黑带备考冲刺每日一练 PWA V3.0

本版在 V2.5.1 基础上完成三项升级：

## 1. 题库全量扩充：81 题 → 600 题

- 覆盖《模拟测试题 2/3/4/5（外发）》四套试卷全部题目（每套 150 题），保留原始题号（如 `T3-087` = 模拟题 3 第 87 题）。
- 标准答案以《模拟测试题N_答案.xlsx》（2025 秦老师发）为准；原有 81 道人工精校题的答案与解析原样保留。
- 新增题目均附简明中文解析；数值题经独立复算核对。
- 跨套完全重复的题（59 题）标记 `dupOf`，不进每日抽题池；答案或题面存疑的题（23 题）标记 `needs_review`，默认排除在抽题池之外，待人工确认。
- 已知答案键存疑题（原始答案保留、已标待核对）共 18 题，例：模拟题5-26（看板功能）、模拟题5-125/题2-145（获取资源应找 Champion）、模拟题4-40（SMART 目标）等。

## 2. 章节练习：按 CSSBB BOK 九大模块选题

- 首页新增「章节练习 · 按 BOK 大纲」面板，可从 I~IX 任一模块单独抽题（5/10/15/20 题）。
- 每个模块显示官方 150 题蓝图权重与当前可用题数。
- 章节练习与每日一练共用评分、解析、AI 追问、打卡与实考预估统计；题目当天固定，可中断续做。

## 3. AI 模式引用 Handbook

- `knowledge.js` 新增 `handbookIndex`：BOK 九大域 ↔ 《The Certified Six Sigma Black Belt Handbook》(3rd ed.) 章节映射（如 Analyze → Ch.20-23）。
- 开启 BYOK AI 后，「单题追问」和「AI 今日诊断」的提示词会随题附带对应 Handbook 参考章节；AI 只能引用这些章节做解释与定位，不得虚构页码，也不得改写题库标准答案。

## 兼容性

- 兼容 V2.5.1 历史成绩、考试日期、昵称、主题与 AI 设置（沿用同一存储前缀）。
- Service Worker 缓存版本：`bb-daily-v3.0.0`（更新后建议强制刷新一次）。

## 部署

将本目录文件覆盖 GitHub Pages 仓库根目录并 Commit，等待部署完成后强制刷新：

- Mac Chrome：`Command + Shift + R`
- iPhone Safari：设置 → Safari → 清除历史记录与网站数据，或直接强制刷新
