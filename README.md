# 黑带备考冲刺每日一练 PWA V2.4

本版修复 V2.3 进入练习后不显示题目的问题，并新增：

- 同一天可完成多轮练习；
- 每轮仍可按 5 / 10 / 15 / 20 题与低 / 中 / 高难度设置；
- 新一轮优先轮换未做题，题库不足时再复用；
- 首页显示当天已完成轮数与最高分；
- 打卡图片始终采用当天最高分；
- 打卡图片明确显示“已连续打卡 N 天”；
- 兼容旧版历史数据；
- Service Worker 缓存升级为 bb-daily-v2.4.0。
