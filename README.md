# 黑带备考冲刺每日一练 PWA V2.5.1

本版在 V2.5 基础上修复“100% 新题仍可能混入旧题”的问题：

- 首轮默认以约 80% 新题 + 20% 旧题推进；“新题”定义为过去 4 周未出现过的题。
- 系统根据过去 7 天日均练习题量动态调整：练得少，提高新题比例；练得多，适度增加旧题复习。
- 设置考试日期后，系统会根据尚未覆盖题数与剩余天数自动提高新题比例，目标是在考试前至少把整套题库过一遍。
- 第二轮及之后显示新旧题比例滚动条，可按 10% 步进自由选择 0%–100% 新题。
- **100% 新题为严格模式**：只抽“从未做过”的题；如果剩余从未做过的题少于本轮题量，则本轮自动缩短，绝不拿旧题补位。
- 0%–90% 模式中的“新题”仍按“过去 4 周未出现”定义；目标池充足时严格按设定比例抽取。
- 抽题时优先安排“从未做过”的题，其次才是超过 4 周未出现的题；旧题复习会提高历史错题权重。
- 保留 5 / 10 / 15 / 20 题和低 / 中 / 高难度。
- 新增 7 种界面主题：默认、二次元、科幻、学霸、中国风、哪吒·国潮神话、古希腊·奥德赛。
- 打卡图会随所选主题改变主色，并继续采用当天最高分、显示连续打卡天数。
- 兼容 V2.4 历史成绩、考试日期、昵称与 AI 设置。
- 为避免沿用 V2.5 的错误日题集合，本版启用新的 active/daily-set 存储前缀。
- Service Worker 缓存版本：`bb-daily-v2.5.1`。

## V2.5.1 回归测试

2026-09-07 对生产版 `buildDailySet()` 完成 200 次自动抽题回归测试：

- 100% 严格新题：100 / 100 通过；每轮 10 题全部为从未做过的题，旧题补位 0。
- 80% 新 / 20% 旧：100 / 100 通过；题池充足时每轮稳定为 8 道过去 4 周未出现题 + 2 道过去 4 周出现过的题。
- 额外边界：仅剩 5 道从未做过时只出 5 道，不补旧题；剩余 0 道时不出题并提示降低新题比例。
